Privacy Policy — Kishan Health Sync

Last updated: November 13, 2026.

Kishan Health Sync is a personal, one-user app that copies daily wellness data from Google Health to Intervals.icu for Kishan Ramachandran.

Data collected

This website collects no data. It has no forms, no analytics, no cookies, and no login.

The sync itself, run on GitHub Actions, reads these Google Health data types, with the user's consent: daily resting heart rate, daily heart rate variability, sleep, daily oxygen saturation, daily respiratory rate, daily VO2 max, and steps. It writes them as wellness fields to the user's own Intervals.icu account. It writes wellness only, no workouts.

Data storage and sharing

Health data is not stored by this website and is not shared with any third party. The sync passes data directly from Google Health to Intervals.icu. Credentials are stored only as GitHub Actions Secrets, accessible to the repository owner.
